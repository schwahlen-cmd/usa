USA REISE 2026 – iPhone PWA

1. Den gesamten Ordner auf einen HTTPS-Webserver hochladen (z. B. GitHub Pages, Netlify oder eigener Webspace).
2. Die HTTPS-Adresse auf dem iPhone in Safari öffnen.
3. Teilen > Zum Home-Bildschirm > Hinzufügen.
4. Danach startet die Reise-App über das Symbol und ist nach dem ersten Laden offline verfügbar.

Die Reisedaten wurden aus der Excel-Reiseliste und den im Gespräch bestätigten Ergänzungen zusammengestellt.
